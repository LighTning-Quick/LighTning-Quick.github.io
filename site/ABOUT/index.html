    易经诠释 / I Ching Interpretation

    《周易》卦爻辞的现代汉语释义与英译。
    Modern Chinese interpretations and English translations of the hexagram and line statements of the Zhouyi.

    访问在线版本 / Visit the website

    项目简介 / About the Project

    本项目以《周易》为核心，对卦辞、爻辞与《象传》进行现代汉语释义和英语翻译，可视为一块辅助理解《易经》语义系统的“数字罗塞塔石碑”。

    本项目围绕各卦卦名，尝试以“卦爻辞作为卦名多义词解释”为基本假设梳理各卦含义、及其体现的关系与变化。译文力求在保留原文结构与关键意象的同时，呈现各爻在卦象发展“太极图”过程中的语义位置，在辞的构成中体现象的魅力。

    Centered on the Zhouyi, this project offers modern Chinese interpretations and English translations of the hexagram statements, line statements, and the Commentary on the Images. It may be regarded as a “digital Rosetta Stone” designed to aid understanding of the semantic system of the I Ching.

    Organized around the name of each hexagram, this project adopt a working hypothesis: the hexagram and line statements function as glosses on the multiple meanings of that name. On this basis, the project traces the meanings of each hexagram and the relationships and transformations they embody. While preserving the structure and key imagery of the source text, the translations seek to locate each line within the semantic progression represented by the hexagram’s “Taiji diagram.” Therefore, we strive to embody the charm of imagery in the composition of words.

    页面结构 / Page Structure

    每一卦的译文通常包含以下部分：

    中文内容 English description
    卦名及核心义象 Hexagram name and its central image or semantic range
    卦辞 Original hexagram statement, modern Chinese interpretation, and English translation
    《象》传 The Image commentary and its translation
    初爻至上爻 Each line statement, with its interpretive label and translation
    用九或用六 The special all-nine or all-six statement, where applicable

    本站内容仍在持续整理中；术语和译文可能随研究推进而修订。
    This is an evolving work. Terminology and translations may be refined as the research develops.

    本地使用 / Local Use

    预览 / Preview

    cd 卦爻翻译
pip install mkdocs-material
mkdocs serve

    然后访问 http://127.0.0.1:8000/。
    Then open http://127.0.0.1:8000/ in a browser.

    构建 / Build

    mkdocs build --strict

    生成的网站位于项目根目录的 site 文件夹。
    The generated website is written to the site directory at the project root.
