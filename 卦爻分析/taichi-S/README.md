# 太极 S 一笔拉伸

这是一个独立的 WebGL 网页子模块，用于把太极图中的“一笔线”从二维平面沿 z 轴拉伸成空间曲线。

## 文件结构

- `index.html`：页面入口与控制面板。
- `main.js`：WebGL 渲染、路径建模、交互、图式标注逻辑。
- `styles.css`：页面与标注样式。
- `hexagram-data.js`：卦名、六爻图式、四字成语图式、综卦关系数据。
- `太极拉伸.pptx`：保留的演示文件，目前网页不依赖它。

## 使用方式

直接双击打开 `index.html` 即可运行，不需要安装依赖。

主要操作：

- 左键拖动画布：旋转视角。
- 鼠标滚轮：缩放视角。
- 右键拖动画布：整体平移曲线。
- `提升`：控制从平面到空间曲线的拉伸程度。
- `平滑`：控制六个高度控制点之间的高度插值平滑度。
- `速度`：控制自动提升动画速度。
- `暂停/播放`：控制自动动画。
- `对称曲线`：显示俯视图完全重合、z 方向反向提升的综卦曲线。
- `归位`：重置视角、提升、平移和模式。

## 图式标注

在 `卦名` 输入框中输入卦名，例如 `大有`，点击 `标注图式`：

- 原曲线按一笔画顺序 `1 -> 6` 标注本卦图式。
- 打开 `对称曲线` 后，对称曲线标注综卦图式。
- 对称曲线的 z 方向与原曲线相反，因此综卦图式按由下而上的顺序重排显示。
- 点击 `四字成语` 可在普通图式和四字成语图式之间切换。

## 建模约定

俯视图保持为固定的太极一笔线：

1. 从左下控制点起笔。
2. 沿左侧外圆上行到顶点。
3. 经由两个内部半圆构成 S。
4. 到底点后沿右侧外圆上行到右上控制点。

拉伸只改变 z 坐标，不改变 xy 俯视相对位置。

高度控制点按一笔画顺序由下到上排列：

`1, 2, 3, 4, 5, 6 = 0, 0.2, 0.4, 0.6, 0.8, 1`

控制点之间使用单调三次 Hermite 插值，以避免在控制点处出现明显折顿或切线过平。

## 更新数据

如果外部两个图式表或本仓库卦文件更新，需要重新生成 `hexagram-data.js`。当前生成逻辑是在 Codex 会话中用 PowerShell 脚本完成的，核心规则是：

1. 读取本仓库卦文件，记录卦名、文件名、可用的本地图式和显式综卦。
2. 用 `爻辞图式.md` 覆盖普通图式。
3. 用 `四字爻辞图式.md` 增加四字成语图式。
4. 用标准综卦配对表补全综卦关系。
5. 写出 `window.HEXAGRAM_SCHEMAS = ...` 到 `hexagram-data.js`。
