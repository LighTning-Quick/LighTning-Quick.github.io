## 关于 / About

本项目基于《周易译注》与黎批整理，提供卦爻辞的现代翻译与诠释。

This project is based on "Zhouyi Translation and Annotation" and Li's commentary, providing modern translation and interpretation of the hexagram and line statements.

---

## 翻译格式 / Translation Format

每卦包含以下内容：

| 内容 | Description |
|------|-------------|
| 卦名 | Hexagram name with English translation |
| 卦辞 | Hexagram statement (Guaci) - original Chinese, modern interpretation, and English translation |
| 《象》曰 | The Image (Xiang) - commentary with translation |
| 初九至上九 | Line statements (Yaoci) - each with interpretation and translation |

## 使用 / Usage

### 本地预览 / Local Preview

```bash
cd 卦爻翻译
pip install mkdocs-material
mkdocs serve
```

访问 `http://127.0.0.1:8000`

### 构建 / Build

```bash
mkdocs build
```

输出在 `site` 目录。
